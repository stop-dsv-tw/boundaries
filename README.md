# 說不，也可以

親密關係與數位性影像界線｜國中・高中互動教材

> 這一次，對方不是陌生人。是你喜歡、你信任，甚至正在一起的人。
> 就算是這樣的人，你也有說不的權利。

**線上使用：** https://10033641tycg.github.io/boundaries/

## 這是什麼

一套用手機聊天介面呈現的互動教材，聚焦親密關係裡的性影像壓力：以喜歡為名的試探、以分手要脅、傳過一次之後被「反正你已經傳過了」綁住，以及被傷害之後想以同樣方式報復的岔路。孩子在每個關鍵時刻自己選擇怎麼回，對方的語氣會隨孩子的選擇改變，玩完後看到自己最容易在哪一種時刻鬆口。

情境取材自兒少性剝削實務案件的常見型態，加以改編、虛構，不代表任何特定個案，不含露骨內容。

## 適用對象與使用原則

- 對象為**國中**與**高中／高職**學生，進入時可選年齡與性別（男生／女生／都可以），劇情共用，性別只改變對象稱呼。
- **用於個案時，請由受過訓練的專業人員全程陪同**，不要讓個案單獨使用。內容會模擬被一步步誘導的過程，可能勾起曾有相關經驗者的情緒。
- 第四關「換我握有他的東西」（被害與加害的岔路）僅開放高中／高職身分。

## 四個關卡

| 關卡 | 情境 | 記住這句就好 |
|---|---|---|
| 你願意就代表你愛我 | 曖昧中，他開始用「喜歡」逼你 | 喜歡你的人，會在你說不的時候停下來，而不是更用力 |
| 不然我們就分手 | 交往一個月，他拿分手逼你 | 能用分手逼你的人，給你的本來就不是平等的愛 |
| 反正你已經傳過了 | 傳過一次之後，被既成事實綁住 | 傳過一次，不代表你以後不能說不 |
| 換我握有他的東西 | 被傷害之後的報復衝動（高中限定） | 他傷害你是他的錯；但你發回去，會把自己也搞進去 |

完成全部關卡後解鎖統整報告，整理孩子跨關最容易鬆口的類型：怕他離開、怕他不開心、懷疑自己想太多、反正都已經這樣了。國中版的統整報告另附「散布他人性影像違法」的明確提醒。

## 給陪伴者的功能

- **檢視結果**：保留孩子第一次自己作答的內容，重玩不會覆蓋，方便事後一起回顧。建議問法是「當下那一句，你心裡在想什麼？」
- **清除紀錄**：換下一位使用前請先清除。
- **資料不外傳**：作答與使用者資訊只存在該裝置的瀏覽器中，不會上傳。
